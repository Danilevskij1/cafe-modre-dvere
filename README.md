# Cafe Modré dveře — website concept

Responsive Czech / English one-page website for a café in Kostelec nad Černými lesy.

## Deploy on GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.

The public URL after successful deployment will be:
https://danilevskij1.github.io/cafe-modre-dvere/
